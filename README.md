# Lucky Number: Las Vegas Strip night drive

Web build of a night drive down a stylized Las Vegas Strip, made in Unity.

Play: https://realcraig.github.io/lucky-number-strip/

Press V in the demo to switch between the driver's seat and the hood camera.

Map data © OpenStreetMap contributors (ODbL). Elevation from USGS 3DEP lidar (public domain).
Casino names and logos are parodies.
